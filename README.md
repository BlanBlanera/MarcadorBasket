Este es un proyecto para tener un marcador de basket sin anuncios. Esta primera versión es de mini-basket (6 tiempos de 8 minutos)
Archivo	Para qué sirve
index.html	Define la estructura: equipos, puntos y botones.
styles.css	Controla los colores, tamaños y distribución en pantalla.
script.js	Gestiona las puntuaciones, los seis periodos y el guardado automático
